# Quizly 免费版

一个可自托管、无需付费服务的 Kahoot 风格互动答题应用。

## 运行

```bash
npm start
```

打开 `http://localhost:4399`。主持人和玩家使用同一局域网时，可将 `localhost` 换成运行电脑的局域网 IP。

当前网络下的局域网地址是 `http://10.0.165.55:4399`。手机和其他电脑需要连接同一个 Wi-Fi，然后访问这个地址；主持人房间页也会显示实时局域网地址。

当前 Mac 也可通过 `com.quizly.local` LaunchAgent 在后台自动运行，无需保持终端窗口打开。

## 功能

- 注册、登录、退出，密码使用 Node `scrypt` 哈希并保存到本地 `data.json`
- 注册时填写邮箱，后续登录使用昵称（用户名）和密码；服务端仍兼容邮箱登录
- 个人题库：创建题库、编辑题目、设置正确答案和答题时间
- 房间码加入；主持人控制开始、结束本题、查看积分榜和下一题
- 4 色答案块、倒计时、按答题速度计算积分：基础分 100，按答题秒数线性递减（10 秒题第 1 秒 100 分、第 2 秒 90 分，最后 10 分），连续答对加分状态
- 每题可设置标准分、双倍分或不计分；答题、揭晓、倒计时和积分榜提示音
- 选择题、判断题、填空题，以及每题图片上传
- SSE 实时同步主持人和玩家状态

这是适合个人/局域网部署的免费版。生产环境建议在反向代理后运行，并将 `data.json` 放入受保护的持久化目录。
